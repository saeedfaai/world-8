## Screening rules for World 8

A competition is worth entering only if:
1. entrant/team is explicitly eligible under official rules;
2. pre-existing World 8 code is permitted or the submission is a genuinely new qualifying build;
3. required public repo/demo/video can be provided without violating repository/privacy constraints;
4. no claim exceeds frozen evidence;
5. required sponsor technology is actually used, not added cosmetically;
6. submission can point to a specific release/commit/DOI/demo receipt.
